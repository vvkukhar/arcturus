# Інструкція щодо незаповнених змінних у .env

OPENAI_API_KEY
- Джерело: platform.openai.com -> Навігація ліворуч -> API Keys -> Create new secret key.

LIQPAY_PUBLIC_KEY / LIQPAY_PRIVATE_KEY
- Джерело: liqpay.ua -> Авторизація -> Налаштування компанії -> API -> Public Key / Private Key.

SENTRY_DSN
- Джерело: sentry.io -> Create Project (Nest.js / Node.js) -> Settings -> Client Keys (DSN).
